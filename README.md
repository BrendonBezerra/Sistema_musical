🎵 Sistema Musical
O Sistema Musical é um projeto desenvolvido para organizar e visualizar informações sobre artistas e músicas. A interface permite acessar uma área de login, cadastrar artistas, adicionar músicas e consultar uma biblioteca musical.
✨ Funcionalidades
- Login: tela de acesso ao sistema.
- Menu principal: atalhos para as principais áreas.
- Cadastro de artistas: formulário com nome, gênero musical, país e foto.
- Cadastro de músicas: formulário com artista, título, álbum, gênero, link do YouTube, capa e letra.
- Biblioteca musical: listagem de músicas com filtros por título, álbum, artista e gênero.
🛠️ Tecnologias utilizadas
- HTML5: estrutura das páginas.
- CSS3: estilos, layout e responsividade da interface.

▶️ Como executar
1. Faça o download ou clone este repositório:
   git clone https://github.com/BrendonBezerra/Sistema_musical.git
2. Abra a pasta do projeto.
3. Execute o arquivo login.html em um navegador.
4. Para acessar a tela principal diretamente, abra index.html.

Observação: esta versão do repositório apresenta a interface em HTML e CSS, com dados demonstrativos nas tabelas. Os formulários ainda não estão conectados a um sistema de autenticação ou banco de dados; portanto, o cadastro, a edição, a exclusão e os filtros não representam operações persistentes nesta versão.
